# ES-PET RC7 — phone mission and XP guide

Each pet draws **3 daily missions** from the eligible pool. Progress resets
with the local date. Time-window missions only count activity inside the stated
window. Finish all three for a **+200 XP perfect-day bonus**.

## Daily missions

| Mission | Requirement | XP |
|---|---|---:|
| Stretch Your Legs | 1,500 steps | 100 |
| Signal Safari | 20 Wi-Fi identities first seen today | 100 |
| Social Spark | 25 Bluetooth identities first seen today | 100 |
| Early Bird | 500 steps before 10:00 | 150 |
| Lunch Walk | 400 steps from 12:00–13:59 | 150 |
| Evening Mixer | 15 Bluetooth identities first seen from 18:00–22:59 | 150 |
| Go Exploring | Start 1 adventure | 150 |
| New Horizons | Discover 8 Wi-Fi identities never seen by this pet | 150 |
| Bluetooth Trail | Discover 12 Bluetooth identities never seen by this pet | 150 |
| Home Again | Finish 1 adventure by returning HOME | 150 |
| Weekend Wander | 2,500 steps on Saturday or Sunday | 200 |
| Monday Momentum | 1,800 steps on Monday | 200 |
| Friday Roam | Start 1 adventure on Friday | 200 |
| Big Day Out | 5,000 steps | 250 |
| Double Adventure | Start 2 adventures | 250 |

Availability notes:

- Early Bird is only put in the pool if missions are generated before 10:00.
- Lunch Walk is only put in the pool if generated before 14:00.
- Evening Mixer is only put in the pool if generated before 23:00.
- Weekend Wander, Monday Momentum and Friday Roam only appear on their named
  days.
- “First seen today” can include a familiar identity on its first sighting of
  the day. “Never seen” means genuinely new to that pet's lifetime memory.

## Other XP in RC7

| Source | XP rule |
|---|---|
| Wi-Fi discovery | New-ever +4; familiar first-seen-today +2; new channel +2 |
| Ordinary Bluetooth discovery | New-ever +2; familiar first-seen-today +1 |
| Daily radio ceiling | Wi-Fi + ordinary Bluetooth combined stop at 100 XP per local day |
| Genuine new ES-PET peer | +100 per distinct peer, once; outside the radio ceiling |
| Perfect mission day | +200 when the third daily mission completes |

Repeated sightings already seen that day give no discovery XP. Mission,
challenge, badge and genuine-peer rewards do not consume the 100-XP radio
allowance.

## RC6 upgrade promise

RC7 does not subtract or recalculate old XP. A pet arriving with about 84K XP
keeps it. The new balance applies only to rewards earned after RC7 starts.
